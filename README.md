## 📊 Excel

- [ ] Fórmulas básicas (SOMA, MÉDIA, SE, CONT.SE)
- [ ] Referências relativas x absolutas
- [ ] PROCV / PROCX (VLOOKUP / XLOOKUP)
- [ ] Tabelas dinâmicas (Tabela Dinâmica)
- [ ] Gráficos dinâmicos
- [ ] Formatação condicional
- [ ] Funções de texto (CONCATENAR, ESQUERDA, DIREITA, EXT.TEXTO)
- [ ] Funções de data/hora
- [ ] Validação de dados
- [ ] Introdução a Power Query no Excel
- [ ] Introdução a macros/VBA (opcional)
- [ ] Projeto prático: planilha de controle financeiro ou dashboard simples

## 📈 Power BI

- [ ] Conexão com fontes de dados (Excel, CSV, banco de dados)
- [ ] Power Query: limpeza e transformação de dados
- [ ] Modelagem de dados (relacionamentos entre tabelas)
- [ ] Conceitos de esquema estrela (star schema)
- [ ] DAX básico (CALCULATE, SUM, COUNT, FILTER)
- [ ] Medidas x colunas calculadas
- [ ] Visualizações básicas (barras, linhas, pizza, cartões)
- [ ] Segmentações de dados (slicers) e filtros
- [ ] Criação de dashboards interativos
- [ ] Publicação no Power BI Service
- [ ] Projeto prático: dashboard com dados públicos (ex: IBGE, Kaggle)

## 🗄️ SQL

- [ ] Comandos básicos (SELECT, WHERE, ORDER BY)
- [ ] Filtros e operadores lógicos (AND, OR, IN, BETWEEN, LIKE)
- [ ] Funções agregadas (COUNT, SUM, AVG, MIN, MAX)
- [ ] GROUP BY e HAVING
- [ ] JOINs (INNER, LEFT, RIGHT, FULL)
- [ ] Subqueries
- [ ] CREATE, INSERT, UPDATE, DELETE
- [ ] Chaves primárias e estrangeiras
- [ ] Views
- [ ] Índices (conceito e uso básico)
- [ ] Funções de janela (window functions) — nível intermediário
- [ ] Projeto prático: modelagem e consultas em um banco de dados próprio
